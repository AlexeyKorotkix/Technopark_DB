# TechnoPark-DB * Информационная система учёта оборудования лаборатории

> **Разработка веб-приложения для учёта оборудования, резидентов и использования материально-технической базы технопарка**

Курсовая работа по специальности **«Информационные системы и программирование»**.

## О проекте

Проект представляет собой информационную систему для автоматизации учёта оборудования лаборатории технопарка. Система разработана на базе веб-технологий Python/Flask и предназначена для использования в образовательных учреждениях, для управления материально-техническими ресурсами и контроля выдачи оборудования.

### Ключевые возможности
* **Учёт оборудования:** Полная информация о каждой единице техники - от серийного номера до текущего статуса (доступно / в использовании / в ремонте / списано).
* **Управление аудиториями:** Структурированное хранение данных о лабораториях и помещениях с привязкой оборудования.
* **Журнал выдач:** Автоматизированный учёт выдачи оборудования резидентам с фиксацией даты, цели и ответственного лица.
* **Многоуровневая авторизация:** Три роли пользователей - администратор, оператор и наблюдатель (только просмотр).
* **SQL-консоль:** Встроенный инструмент для выполнения произвольных SQL-запросов к базе данных.

## Технологический стек

| Компонент | Технология |
| :--- | :--- |
| **Backend** | Python 3.10+, Flask 3.0 |
| **База данных** | SQLite 3  |
| **Авторизация** | Flask-Login, Werkzeug (хэширование паролей) |
| **Защита форм** | Flask-WTF (CSRF-токены) |
| **Frontend** | HTML5, Jinja2, Bootstrap 5, Bootstrap Icons |
| **Стилизация** | Собственные CSS + JS для интерактивности |

## Архитектура системы

Система построена по классической трёхуровневой архитектуре:

1. **Уровень представления (Presentation):** HTML-шаблоны Jinja2 с Bootstrap 5. Отвечает за отображение данных и взаимодействие с пользователем.
2. **Уровень бизнес-логики (Business Logic):** Flask-приложение с модульной структурой (Blueprints). Обрабатывает запросы, выполняет валидацию, управляет сессиями.
3. **Уровень данных (Data):** SQLite-база данных с нормализованной схемой (6 таблиц, внешние ключи, индексы).

**Модульная структура:**
- `routes/auth.py` - авторизация и управление сессиями
- `routes/dashboard.py` - панель управления со статистикой
- `routes/laboratories.py`, `rooms.py`, `equipment.py` - CRUD-операции для лабораторий, помещений и техники
- `routes/residents.py`, `usage.py` - учёт резидентов и выдач
- `routes/sql_console.py` - SQL-консоль (только для admin)

## Быстрый старт

### Требования к системе
* Python 3.10 или выше
* Git (для клонирования репозитория)
* Веб-браузер (Chrome, Firefox, Edge)

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AlexeyKorotkix/Technopark_DB
   cd Technopark_DB
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   # Создание и вход в виртуальное окружение:
   python -m venv venv
   # Активация виртуального окружения:
   venv\Scripts\activate


3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Инициализируйте базу данных и запустите приложение:
   ```bash
   python init_db.py
   python app.py
   ```

5. Откройте в браузере: `http://127.0.0.1:5000`
